Alibre Design Script Addon Template

This repository provides a complete Visual Studio project template for creating Alibre Script-based addons with Python integration. The template includes a working addon framework and example scripts to help developers quickly start building their own Alibre Design addons.

## Features

- **Visual Studio Project Template** - Complete template for rapid addon development
- **Python Script Integration** - Execute Python scripts from within Alibre Design
- **Dynamic Menu System** - Automatically generates menus from your Python scripts
- **Example Implementation** - Working steel shapes addon included as reference
- **Parameterized Templates** - Easily customize for your specific addon needs

## Quick Start

1. **Install the Template**: Follow the instructions in `TEMPLATE_INSTALLATION.md`
2. **Create New Project**: Use "Alibre Design Script Addon" template in Visual Studio
3. **Customize Scripts**: Add your Python scripts to the Scripts folder
4. **Build and Deploy**: Build the project and copy to Alibre Design addons directory

## Template Structure

The template creates a complete addon project with:
- C# addon framework with menu integration
- Python script execution engine
- Example Python scripts
- Proper project configuration for Alibre Design
- Documentation and installation guides
